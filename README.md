# 시험 자료 정리 사이트

https://kingjellybear-dotcom.github.io/Exam/

## 파일 구조

```
Exam/
├─ index.html        화면·검색·탭 등 "틀". 거의 건드릴 일 없음
├─ README.md         이 설명서
└─ data/
   ├─ config.js      시험 날짜, 사이트 제목, 과목 목록
   ├─ kor.js         국어 자료
   ├─ math.js        수학 자료
   ├─ sci.js         과학 자료
   ├─ hist.js        역사 자료
   └─ eng.js         영어 자료
```

## 자주 하는 작업

| 하고 싶은 일 | 고칠 파일 |
|---|---|
| 시험 날짜(D-day) 넣기 | `data/config.js`의 `date: "2026-12-15"` |
| 과목의 단원 추가·수정 | 해당 과목 파일 (`data/sci.js` 등) |
| 과목 이름·교과서 표기 변경 | `data/config.js`의 `SUBJECTS` |
| 새 과목 추가 | `config.js`에 한 줄 + `data/새id.js` 파일 생성 |
| 디자인 변경 | `index.html` (Claude에게 요청 권장) |

## 단원 자료 형식 (data/과목.js)

```js
UNITS.sci = [
  { title: "[단원명] 1. 소제목", items: [
    `일반 내용`,
    `서술형 대비 모범 답안: "...(원인), ...(과정), ...(결과)"`,
    `출제자 함정 포인트: ...`
  ]},
  { title: "[단원명] 2. 다음 소제목", items: [
    `내용`
  ]}
];
```

- 단원(`{ ... }`) 사이에는 쉼표(,)가 반드시 필요해.
- 마지막 단원 뒤에는 쉼표가 있어도 없어도 돼.
- 내용은 백틱(`)으로 감싸. 안에 큰따옴표·작은따옴표는 자유롭게 써도 돼. 백틱 문자 자체만 쓰지 마.
- 내용이 "서술형 대비"로 시작하면 파란 박스, "출제자 함정"으로 시작하면 노란 박스로 자동 표시돼.

## 새 과목 추가 예시 (사회)

1. `data/config.js`의 `SUBJECTS`에 한 줄 추가: `{ id: "soc", name: "사회", book: "교과서 이름" },`
2. `data/soc.js` 파일을 만들고 `UNITS.soc = [ ... ];` 작성

## GitHub에서 수정하는 법

1. 저장소 `kingjellybear-dotcom/Exam`에서 고칠 파일을 연다.
2. 연필 아이콘(Edit) → 수정 → 오른쪽 위 **Commit changes** → 한 번 더 Commit.
3. 1~2분 뒤 사이트에서 새로고침(안 바뀌면 강력 새로고침).

## 문제가 생기면

- 해당 과목만 "자료 없음"으로 보이거나 아무것도 안 뜨면, 그 과목 파일의 쉼표·괄호·백틱이 빠졌는지 확인.
- 다른 과목은 영향 없음. 고치기 전 상태로는 파일의 **History**에서 되돌릴 수 있어.
